# Irene and Dani's Homewood

A pixel-art map of the JHU Homewood campus with 17 of our spots on it. Press Start, tap a heart, and the two of us walk there and show the memory.

Open `index.html` in a browser.

The background song (10CM, "Spring Snow") isn't included because it's a commercial track. To add it, drop an MP3 named `music.mp3` in this folder. The music button only shows up when that file is there.
